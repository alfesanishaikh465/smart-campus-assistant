# Smart Campus Assistant

An AI-powered Smart Campus Assistant built using Python, Streamlit, SQLite, and Google Gemini API.

## Features
- View class timetable
- AI-powered campus assistance using Gemini API
- FAQ support
- SQLite database integration
- Deployed on Streamlit Cloud

## Technologies Used
- Python
- Streamlit
- SQLite
- Google Gemini API
- Git & GitHub
